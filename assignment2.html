Assignment 2 - Parallel Prototypes

FocusScape

Exploring different ways of controlling and experiencing a browser-based soundscape for focused study.

01

Prototype Overview

FocusScape is a browser-based audio instrument designed to create evolving background soundscapes for studying. These parallel prototypes explore different approaches to information design, interaction and randomisation without changing the main purpose of the project.

02

Area One - Information Design

These prototypes explore how much control and information should be visible while someone is studying. Each version presents the same general soundscape idea through a different interface.

Prototype 01

Individual Controls

This version gives each sound layer its own control. It explores whether direct access to individual sounds makes the soundscape easier to personalise.

Open Prototype →

Prototype 02

Atmosphere Presets

This version groups sounds into atmosphere presets. Instead of adjusting every layer, the user can quickly choose an environment that suits their study session.

Open Prototype →

Prototype 03

Minimal Focus Mode

This version reduces the number of visible controls. It explores whether a simpler interface can reduce distraction while still giving the user enough control.

Open Prototype →

03

Area Two - Randomisation & Feedback

These prototypes explore different ways of using controlled randomisation to make the soundscape feel less repetitive. This area develops the extended technique proposed in Assignment 1.

Prototype 04

Automatic Variation

This version uses subtle automatic variation in the soundscape. Random values are kept within a limited range so changes can occur without demanding attention.

Open Prototype →

Prototype 05

Generate Variation

This version lets the user trigger a new variation. It explores a more direct relationship between user input and the randomisation technique.

Open Prototype →

Prototype 06

Variation Feedback

This version makes changes in the soundscape more visible through small feedback messages. It explores how users can understand what is changing without adding too much visual distraction.

Open Prototype →

04

Git Commit Logs

Version history from the parallel prototype development will be documented here.

Prototype 01 - Individual Controls

Developed separate controls for rain, café ambience, wind and tone to explore direct personalisation of the soundscape.

Prototype 02 - Atmosphere Presets

Replaced individual controls with preset environments to explore a faster and less detailed setup process.

Prototype 03 - Minimal Focus Mode

Reduced the interface to atmosphere and intensity controls to test a lower-distraction approach.

Prototype 04 - Automatic Variation

Added controlled automatic changes using Math.random() so the soundscape can evolve without repeated user input.

Prototype 05 - Generate Variation

Changed randomisation from automatic to user-triggered, allowing the user to decide when a new variation is generated.

Prototype 06 - Variation Feedback

Added visible feedback explaining which sound layers increased, decreased or stayed the same after each variation.
